Untrustworthy points visualization

Each point twice over. Level is the mean of its four per-point metrics, less a penalty for how much they disagree: a point the metrics cannot agree on is not one you can call faithful, so the disagreement costs it. Evenness is 1 − (max − min) across those same four, so it answers “do the metrics agree about it?”. A point is Untrustworthy if either reading is red, Medium if either is amber, and Trustworthy only when both are green: a high Level with poor Evenness is not a clean point, it is a point whose verdict depends on which metric you ask.
