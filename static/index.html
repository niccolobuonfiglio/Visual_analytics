Neighbourhood search  simulated annealing

—
Why this is needed. The F1-score as a function of the neighbourhood size k is neither concave nor convex: enlarging k steadily raises recall but lowers precision in a bumpy way, so the combined score has several local peaks. A plain scan is wasteful and gradient methods get stuck, so the toolkit anneals — it accepts occasional worsening moves early on to escape local optima, then cools to refine. Crucially, no projection is recomputed during the search; only the similarity graph is rebuilt, which is what makes it cheap.

Cluster-structure metrics  precision · recall · F1

—
What this asks. Separately from projection fidelity, are the classes genuinely present as clusters in the high-dimensional data? Precision asks whether a point is surrounded by its own class; recall asks whether each class holds together; F1 is their harmonic mean. These are computed on the data itself, so a low score is a property of the data, not of any projection.

Ground-truth check  k-means

—
Why it matters. Every supervised score above trusts the class labels. k-means clusters the data with no labels and asks whether those clusters line up with the classes. If they do not, an apparent "projection error" may really be a mismatch between the labels and the data's natural groups — so this check runs before the verdict is trusted.
