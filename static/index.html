Error Space

Integrated exploration across all three views at once: the PCA and MDS projections on top, and the error space (PCA error vs MDS error) below. Drag a box or lasso on any plot to select points -> the same points ring on all three. Or click a quadrant below to select every point whose PCA/MDS error signs match. Selection detail appears in the shared table.

By default the error is geometric: it counts any broken neighbour, measuring whether the projection preserved the data’s geometry — with no assumption that the labels are right. Class-aware counts only cross-class intrusions and same-class extrusions, so it measures whether the projection preserved the labelled class structure. The two can disagree sharply (on Wine, on ~70% of points), which is itself informative: a point distorted geometrically but faithful class-wise had its neighbourhood reshuffled only within its own class. The number on the right reports how much the two modes differ on the current data.

Trust Analysis — which points can I not trust?

Each point acts as a classifier of its own neighbourhood: its high-D k-nearest neighbours are the “truth”, its 2-D k-nearest neighbours are the “prediction”. Precision = fraction of the 2-D neighbours that are real (1 − precision = false-positive/intrusion rate); Recall = fraction of the real neighbours the projection kept (1 − recall = false-negative/extrusion rate); F1 = their harmonic mean, in [0,1]. A low-F1 point cannot be trusted — its neighbourhood in the picture is wrong. Colour below is the per-point F1 (red = untrustworthy, green = faithful).

F1 vs JS fidelity — where the two metrics disagree

Each point plotted by its neighbour-F1 (x) against its JS fidelity (y), for the chosen method. Points on the diagonal agree; points far off the diagonal are judged very differently by the two metrics — e.g. high F1 but low JS fidelity means the projection kept the right k neighbours but badly distorted their relative affinities. Those are the interesting, ambiguous points.

Cluster-structure metrics  purity · cohesion · F1

—
What this asks. Separately from projection fidelity, are the classes genuinely present as clusters in the high-dimensional data? Purity asks whether a point is surrounded by its own class (formerly “precision”); cohesion asks whether each class holds together as one connected group (formerly “recall”); F1 is their harmonic mean. These are computed on the data itself, so a low score is a property of the data, not of any projection.

Neighbourhood search  simulated annealing

—
Why this is needed. The F1-score as a function of the neighbourhood size k is neither concave nor convex: enlarging k steadily raises recall but lowers precision in a bumpy way, so the combined score has several local peaks. A plain scan is wasteful and gradient methods get stuck, so the toolkit anneals — it accepts occasional worsening moves early on to escape local optima, then cools to refine. Crucially, no projection is recomputed during the search; only the similarity graph is rebuilt, which is what makes it cheap.

Ground-truth check  k-means

—
Why it matters. Every supervised score above trusts the class labels. k-means clusters the data with no labels and asks whether those clusters line up with the classes. If they do not, an apparent "projection error" may really be a mismatch between the labels and the data's natural groups — so this check runs before the verdict is trusted.

Weighted MDS

What it does. Ordinary MDS treats every feature equally when it computes the pairwise distances that drive the layout, so noisy or irrelevant features count as much as informative ones. Weighted MDS scales each feature j by √wj before distances are computed, where wj is the mutual information between feature j and the class label. The layout is then built from the weighted-Euclidean dissimilarity
d(a,b) = √( Σj wj (aj − bj)² )
so features that carry the class signal dominate the geometry and classes tend to separate more cleanly. Only the MDS panel changes — PCA and the high-D fidelity reference stay unweighted, so the error colours still measure distortion from the true geometry, not the reweighted one. The change is measurable: the panel below reports the class silhouette of the plain vs weighted layout, so you can see whether weighting actually improved separation.

Distortion & Balance

Instead of the signed error (which cancels FP against FN), these show the two components directly. Total distortion = FP + FN — the overall magnitude, regardless of direction; a projection with a long right tail here distorts many points badly. Balance = |FP − FN| / (FP + FN) — how one-sided each point's distortion is: 0 means FP and FN are equal (the point is pulled both ways at once, and its signed error misleadingly reads ≈ 0), 1 means the distortion is entirely intrusion or entirely extrusion. Faithful points (FP = FN = 0) are excluded from balance, since it is undefined for them.
